READ FIRST — how PseudoPay actually works (verified from source)
----------------------------------------------------------------
Backend: C:\Users\EVANGEL\Desktop\Vscode\Backend\PseudoPayBackend
- Init: POST {BASE}/api/transaction/initialize/  (Wallet/views.py:64-119)
  Headers: X-Api-Key: sk_pseudo_...  (+ Idempotency-Key: <uuid4>, required)
  Body: {"wallet": <id>, "amount": >=500, "transaction_type": "DEBIT",
         "customer_email": "...", "customer_name": "...",
         "transaction_metadata": {"order_id": ...} | null}
  -> 201: {"transaction_reference": "TRX-...", "checkout_url":
           "http://127.0.0.1:8000/api/checkout/TRX-.../", "transaction_status": "INITIATED", ...}
- Pay: full-page redirect to checkout_url; customer pays with mock card;
  POST /api/checkout/<ref>/ debits wallet, sets SUCCESSFUL.
- Webhook (Wallet/webhooks.py): POST to wallet.request_origin (set via PUT /api/wallet/<id>/)
  payload = {"transaction_id": int, "amount": "1000.00",
             "status": "SUCCESSFUL", "created_at": iso}
  NO signature, NO transaction_reference, NO metadata echo (gap — see M3).
  Also note upstream bug: code reads wallet.profile.request_origin but field lives
  on Wallet.request_origin (Wallet/models.py:27). Merchant must set it on the wallet.
- Idempotency (Payments/req_hash.py + Wallet/views.py:93-108): keyed on
  (profile, Idempotency-Key), 409 on hash mismatch, replay if Completed —
  BUT status is never flipped to Completed, so replay is dead. We do it correctly here.
Frontend: C:\Users\EVANGEL\Desktop\Vscode\Projects\PseudoPayFrontend

- Reusable bits: axios JWT-refresh pattern (api/axios.js), generic Modal/Button

M2 — Idempotent order creation [DONE]
--------------------------------------
Goal: double-click / retry with same Idempotency-Key never double-charges or double-orders.
[x] store/models.py: Order += pseudopay_reference (CharField blank),
    checkout_url (URLField blank). (IdempotencyRecord already correct — add migration.)
[x] makemigrations + migrate (new 0017_*.py).
[x] store/views.py OrderListCreateView.post rewrite:
    1. Require `Idempotency-Key: <uuid4>` header -> 400 otherwise.
    2. hash = hash_request({metadata, email}) via services.hash_request.
    3. get_or_create(IdempotencyRecord(user, key)) + select_for_update;
       mismatch -> 409; hit with same hash -> replay stored {status, data} (no new order,
       no new PseudoPay call).
    4. Else: create Order inside atomic (snapshot cart total, set items, decrement stock,
       detach cart) — NO external HTTP inside the atomic block.
    5. Call PseudoPay initialize OUTSIDE atomic with same Idempotency-Key;
       on failure mark order Failed?/delete + restore stock, return 502 (no silent Initiated).
    6. Store pseudopay_reference + checkout_url on order; save response into record;
       return {order_id, reference, pseudopay_reference, checkout_url,
               authorization_url (= checkout_url, frontend compat), amount, status}.
How to verify: POST /api/order/ twice with same key -> 1 Order row, 1 PseudoPay init
  (mock count == 1), second response replayed; different body + same key -> 409.

[x] store/urls.py: add `pseudopay/webhook/` + `order/<pk>/verify/` (returns current

    frontend to poll — full PseudoPay server-verify needs merchant JWT so we poll
    our own state + rely on webhook; documented below).
[x] Keep `paystack/webhook/` as deprecated 410 with message "use pseudopay/webhook/".
Why no server GET to PseudoPay? GET /api/transaction/ needs merchant JWT (Bearer),
  not API-Key, so DigitalLair (API-Key holder) cannot query it. Recommended upstream
  fix (NOT in this repo): add GET /api/transaction/<ref>/ with API-Key auth and echo
  {transaction_reference, transaction_metadata} in webhook + sign it.
How to verify: POST webhook twice for same order -> Paid once, second 200 replay;
  wrong signature -> 400; unknown ref -> 404. Manual E2E: set wallet.request_origin
  (PUT /api/wallet/<id>/) to https://<ngrok>/api/pseudopay/webhook/, pay on checkout_url.
DONE 2026-10-13: webhook Paid + replay + 404 + 400 + 410 covered in tests.
